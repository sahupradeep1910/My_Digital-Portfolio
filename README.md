# My Digital Portfolio — Semantic HTML5 Portfolio

A professional multi-page personal portfolio website built using semantic HTML5, CSS, and JavaScript. The project focuses on responsive design, accessibility, SEO-friendly structure, and a clean user experience.

## Pages

- `index.html` — Introduction, profile summary, education, skills, and selected projects
- `about.html` — About section, education, technical skills, and professional profiles
- `projects.html` — Detailed project showcase with GitHub links
- `contact.html` — Accessible contact form and professional contact links

## Featured Projects

- **CafeSync** — Dynamic Staff Scheduling System for a Coffee Shop
- **CampusSync** — React-based Campus Services Application
- **QuizMaster** — Interactive Online Quiz Application
- **Tic Tac Toe** — Responsive Two-Player Web Game
- **Asteroid / Space Warship Game** — Space-themed browser game

## Accessibility & Semantic Structure

The website follows accessibility-focused development practices, including:

- Semantic `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` elements
- Skip navigation link
- Logical heading hierarchy
- Visible keyboard focus states
- ARIA labels and live status messaging
- Accessible form labels and validation messaging
- `aria-expanded` and `aria-controls` for mobile navigation
- Reduced-motion support

## Run Locally

Clone the repository:

```bash

```

Navigate to the project directory:

```bash
cd My_Digital-Portfolio
```

Open `index.html` directly in a browser, or serve the project directory using any static HTTP server.
