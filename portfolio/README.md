# Pradeep Kumar Sahu — Semantic HTML5 Portfolio

A multi-page personal portfolio built for the Semantic HTML5 Structure & Accessibility assignment. The site uses semantic landmarks, accessible navigation, ARIA support, keyboard-friendly interactions, SEO metadata and a progressively enhanced contact form.

## Pages

- `index.html` — introduction and selected projects
- `about.html` — profile, skills and development journey
- `projects.html` — detailed project descriptions with GitHub links
- `contact.html` — accessible contact form and professional profiles

## Featured projects

- CafeSync — Dynamic Cafe Hours & Order Management System
- CampusSync — React campus services application
- QuizMaster — Online Quiz Application
- Tic Tac Toe Web Game
- Asteroid / Space Warship Game

## Accessibility & semantic structure

- Semantic `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` and `<footer>` elements.
- Skip link and visible keyboard focus states.
- Logical heading hierarchy with one primary `<h1>` per page.
- ARIA labels, live status messaging and form error association.
- Native form controls with associated labels and required-field messaging.
- Reduced-motion support.
- Mobile navigation implemented with a real button and `aria-expanded` / `aria-controls`.

## SEO

- Unique page titles and descriptions.
- Open Graph and Twitter metadata.
- Person structured data on the home page.
- `robots.txt` and `sitemap.xml` included.
